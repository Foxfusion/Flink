# Flink

Apache Flink streaming and batch-processing workspace.

Use this repository for Flink-specific learning, examples, SQL, stateful streaming patterns, connectors, and deployment experiments.

## Repository boundaries

- **Flink** — Apache Flink
- **Spark** — Spark/Scala and Zeppelin
- **FoxPySpark** — Python/PySpark
- **Data_Engineering** — cross-platform data-engineering patterns

## Layout

- `python/` — PyFlink examples
- `java/` — Java Flink examples
- `sql/` — Flink SQL examples
- `docs/` — architecture and setup notes
- `tests/` — tests

Do not commit checkpoints, savepoints, credentials, large datasets, or generated build/runtime output.
